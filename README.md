# 애즈폼

광고 캠페인 주문·승인, 오퍼월 참여, 포인트 적립, 대행사 충전과 실행사 수익을 한 PC에서 체험하는 로컬 MVP입니다.

[초기 Bizpop 분석 및 MVP 구축 계획](docs/bizpop-benchmark-and-mvp-plan.md)

## 실행

1. Node.js 24 이상이 설치된 PC에서 `start.cmd`를 열거나 프로젝트 폴더에서 `npm start`를 실행합니다.
2. [http://127.0.0.1:3063](http://127.0.0.1:3063)에서 애즈폼을 엽니다.
3. 로그인 페이지의 테스트 버튼에서 최고관리자, 실행사, 대행사, 광고주, 참여자를 선택합니다.

설치할 npm 패키지가 없습니다. 로컬 서버가 처음 실행될 때 `data/demo.sqlite`를 만들며, 승인·잔액·배경 설정은 서버를 다시 실행해도 유지됩니다.

메신저 공유 카드는 HTML의 Open Graph 태그에 설정되어 있습니다. 공개 HTTPS 주소로 배포한 경우 서버 시작 전에 `ADSFORM_PUBLIC_ORIGIN`을 해당 주소의 출처로 설정하면 공유 이미지와 페이지의 주소가 공개 주소로 표시됩니다. 이 환경 변수는 메타 태그의 URL을 설정합니다. 카카오톡에서 카드를 읽으려면 페이지와 공유 이미지가 외부에서 접근 가능해야 합니다.

## 확인 흐름

- **계정별 대시보드** — 로그인 후 좌측 메뉴에서 해당 역할의 기능을 사용합니다. 모바일에서는 상단 메뉴 버튼으로 좌측 메뉴를 열 수 있습니다. 메뉴 하단에는 프로필과 메인으로 이동하는 버튼이 있습니다.
- **PC 화면** — 최고관리자 좌측 메뉴 → PC 배경 → 배경 5종 중 하나 선택
- **문의 접수** — 메인페이지 문의하기 버튼으로 문의를 남길 수 있습니다. 최고관리자는 좌측 메뉴의 문의 내역에서 내용을 확인합니다.
- **실행사 수익** — 실행사 → 하위 대행사 등록 → 생성한 대행사로 일반 로그인 → 충전 신청 → 최고관리자로 승인 → 실행사 수익 원장 확인
- **수익률** — 최고관리자 → 계정·수익률 → 전체 기본값 또는 개별 실행사 값 설정. 빈 개별 설정은 기본값을 사용합니다.
- **광고·오퍼월** — 광고주 → 주문 등록 → 최고관리자 승인 → 참여 시작으로 자리 확보 → 답변 제출 → 퀴즈 자동 적립 또는 설문 검수 후 적립

미션 자리는 최대 10분간 유지되며 집행 마감 시각을 넘기지 않습니다. 캠페인 기간이 끝나면 미제출 예약은 효력을 잃습니다. 제출된 응답의 검수가 모두 끝난 뒤 미집행 예산이 자동 반환됩니다. 주문 상세에서 승인 집행액과 반환액을 확인할 수 있습니다.

충전 승인 시 대행사에는 승인액 전액이 들어가고, 실행사 수익 원장에는 승인액 × 당시 수익률을 원 단위로 내림한 금액이 별도 반영됩니다. 기본 수익률은 7.5%이며, 과거 승인 건은 승인 당시 적용률을 유지합니다.

## 운영 범위

이 프로젝트는 로컬 체험용입니다. 충전은 수동 승인으로 처리하며 외부 결제와 실제 입금은 연결되어 있지 않습니다. 참여 보상은 내부 테스트 포인트입니다. 쿠폰 발급, 출금, 외부 오퍼월 API는 연결되어 있지 않습니다.

테스트 버튼과 예시 계정을 제외한 별도 로컬 데이터베이스가 필요하면 PowerShell에서 `ADSFORM_DEMO`를 `0`으로 설정합니다. 첫 실행에 한해 `ADSFORM_ADMIN_PASSWORD`로 12~128자의 초기 관리자 비밀번호를 지정합니다. 이 모드의 관리자 아이디는 `admin`이며, 저장 파일은 `data/adsform.sqlite`입니다. 데이터 파일과 초기 비밀번호는 Git에 포함하지 않습니다.

`npm test`로 주문·정산·권한과 중복 방지 흐름을 검증할 수 있습니다.
