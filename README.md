# 애즈폼

광고 캠페인 주문·승인, 오퍼월 참여, 포인트 적립, 대행사 충전과 실행사 수익을 한 PC에서 체험하는 로컬 MVP입니다.

[초기 Bizpop 분석 및 MVP 구축 계획](docs/bizpop-benchmark-and-mvp-plan.md)

## 실행

1. Node.js 22.13 이상이 설치된 PC에서 `start.cmd`를 열거나 프로젝트 폴더에서 `npm start`를 실행합니다.
2. [http://127.0.0.1:3063](http://127.0.0.1:3063)에서 애즈폼을 엽니다.
3. 로그인 페이지의 테스트 버튼에서 최고관리자, 실행사, 대행사, 광고주, 참여자를 선택하거나, 회원가입으로 참여자·광고주 계정을 직접 만듭니다.

설치할 npm 패키지가 없습니다. 로컬 서버가 처음 실행될 때 `data/demo.sqlite`를 만들며, 승인·잔액·배경 설정은 서버를 다시 실행해도 유지됩니다.

메신저 공유 카드는 HTML의 Open Graph 태그에 설정되어 있습니다. 공개 HTTPS 주소로 배포한 경우 서버 시작 전에 `ADSFORM_PUBLIC_ORIGIN`을 해당 주소의 출처로 설정하면 공유 이미지와 페이지의 주소가 공개 주소로 표시됩니다. 이 환경 변수는 메타 태그의 URL을 설정합니다. 카카오톡에서 카드를 읽으려면 페이지와 공유 이미지가 외부에서 접근 가능해야 합니다.

## 확인 흐름

- **계정별 대시보드** — 로그인 후 좌측 메뉴에서 해당 역할의 기능을 사용합니다. 모바일에서는 상단 메뉴 버튼으로 좌측 메뉴를 열 수 있습니다. 메뉴 하단에는 프로필과 메인으로 이동하는 버튼이 있습니다.
- **PC 화면** — 최고관리자 좌측 메뉴 → PC 배경 → 기존 감성 배경 5종과 광고 테마 5종, 총 10종 중 하나 선택. 광고 테마는 광고 기획 스튜디오·콘텐츠 촬영 스튜디오·도심 속 브랜드 광고(실사형), 브랜드 쇼룸·캠페인 성장 가든(일러스트)으로 구성됩니다.
- **문의 접수** — 메인페이지 문의하기 버튼으로 문의를 남길 수 있습니다. 최고관리자는 좌측 메뉴의 문의 내역에서 내용을 확인합니다.
- **실행사 수익** — 실행사 → 하위 대행사 등록 → 생성한 대행사로 일반 로그인 → 충전 신청 → 최고관리자로 승인 → 실행사 수익 원장 확인
- **수익률** — 최고관리자 → 계정·수익률 → 전체 기본값 또는 개별 실행사 값 설정. 빈 개별 설정은 기본값을 사용합니다.
- **광고·오퍼월** — 광고주 → 주문 등록 → 최고관리자 승인 → 참여 시작으로 자리 확보 → 답변 제출 → 퀴즈 자동 적립 또는 설문 검수 후 적립

미션 자리는 최대 10분간 유지되며 집행 마감 시각을 넘기지 않습니다. 캠페인 기간이 끝나면 미제출 예약은 효력을 잃습니다. 제출된 응답의 검수가 모두 끝난 뒤 미집행 예산이 자동 반환됩니다. 주문 상세에서 승인 집행액과 반환액을 확인할 수 있습니다.

충전 승인 시 대행사에는 승인액 전액이 들어가고, 실행사 수익 원장에는 승인액 × 당시 수익률을 원 단위로 내림한 금액이 별도 반영됩니다. 기본 수익률은 7.5%이며, 과거 승인 건은 승인 당시 적용률을 유지합니다.

## 고도화 기능 (2026-11-10)

- **역할별 대시보드** — 광고주·대행사·실행사는 잔액 히어로, KPI(진행 캠페인·오늘 승인·검수 대기·승인율), 14일 참여 추이 차트, 캠페인 상태 도넛, 캠페인 현황 표, 일별 집행 금액, 잔액 내역, 예산 사용 구성을 봅니다. 실행사는 하위 대행사 실적과 수익 추이가 추가됩니다. 최고관리자는 처리 대기 큐, 누적 충전·집행·지급 포인트·실행사 수익 KPI, 일별 충전 승인액, 상품별 성과, 계정 구성, 집행 상위 캠페인, 운영 기록 타임라인을 봅니다. 참여자는 포인트 지갑, 등급(새싹·잎새·나무·숲), 14일 적립 추이, 참여 가능 미션을 봅니다.
- **캠페인 리포트** — 주문 상세에서 일별 승인·검수·반려 차트, 시간대별 참여, 퀴즈 선택지 분포, 설문 응답(참여자 이름 마스킹), 처리 이력, 정산 요약, 운영 메모를 확인합니다. (`GET /api/report?id=`)
- **주문서** — 상품 카드 선택, 일일 모집 한도, 기간 빠른 선택, 운영 메모, 실시간 견적 요약(집행 기간·하루 평균 필요·주문 후 잔액·한도 부족 경고), 기존 주문 재주문.
- **일일 모집 한도** — 하루 승인·검수 중 제출과 유효 예약 합계가 한도에 이르면 그날 신규 참여를 막습니다. 한도 × 기간이 목표보다 작으면 주문을 받지 않습니다.
- **주문 목록** — 검색, 상품·등록 기간 필터, 상태별 건수, 조회 합계(목표·승인·집행·배정 예산).
- **예산** — 충전 금액 빠른 추가, 부가세 포함 입금 예정액 미리보기, 잔액 내역(거래 후 잔액 표시).
- **운영** — 공지사항(전체·광고 계정·참여자 대상, 상단 고정), 미션 검수 상태·상품 필터와 일괄 승인, 좌측 메뉴 처리 대기 배지, 계정 유형 필터와 잔액 표시.
- **데모 이력** — 데모 모드에서 처음 실행하면 2주치 캠페인·참여·충전 기록과 데모 참여자 180명을 생성해 대시보드를 바로 확인할 수 있습니다. 기존 데모 데이터베이스에도 한 번 추가됩니다.

## 점검 반영 (2026-11-11)

전체 점검 보고서의 항목을 순서대로 반영했습니다.

- **버그 수정** — 실행사 충전 화면에 하위 대행사 충전이 합산되던 문제, 잔액 내역에 다른 캠페인명이 표시되던 문제, 홈의 '내 보상'·'광고 주문' 링크가 계정에 맞지 않던 문제, 충전 대기 금액을 이름으로 찾던 문제.
- **계정** — 참여자·광고주 회원가입(약관 동의), 비밀번호·이름 변경, 임시 비밀번호 변경 안내, 관리자의 이용 정지·해제·비밀번호 재설정·이름·소속 변경, 실행사의 하위 대행사 정지·비밀번호 재설정. 삭제 대신 정지로 거래 기록을 보존합니다.
- **보안·남용 방지** — 같은 아이디로 10번 틀리면 15분간 로그인 제한, 문의는 10분에 5건, 가입은 시간당 5건. 공개 주소 배포 시 Secure 쿠키, 사용 중 세션 자동 연장.
- **관리자** — 미션 검수 페이지 나눔·검색과 일괄 승인 확인창(서버에서 한 번에 처리), 충전·출금 반려 사유, 문의 답변(회원은 프로필의 '내 문의'에서 확인), 공지 수정, 운영 기록 검색, 수익률 상한 30%.
- **광고 계정** — 심사 전 주문 취소·내용 수정, 진행 중 캠페인 일시중지·재개·종료, 충전 신청 취소, 부가세 포함 입금액 저장. 실행사는 하위 대행사 캠페인 리포트를 볼 수 있습니다. 시작 전 캠페인은 빈 차트 대신 안내를 보여 줍니다.
- **참여자** — 참여 남은 시간 카운트다운, 보상 내역에 미션명 표시, 퀴즈 선택지 2~5개, 최소 체류 시간(퀴즈 3초·설문 10초), 같은 글자 반복 설문 답변 차단.
- **출금** — 참여자 포인트(5,000P부터)와 실행사 수익(10,000원부터) 출금 신청 → 최고관리자 지급 완료·반려(반려 시 금액 반환).
- **화면** — 모바일에서 표를 카드형으로 표시, 주문서 하단 고정 견적 바, 상단 종 아이콘은 공지사항(새 공지 표시), Pretendard 글꼴 내장(자주 쓰는 한글 2,350자 부분 글꼴, OFL), 이용약관·개인정보처리방침 화면.
- **성능** — 정적 파일 메모리 캐시·gzip 압축·ETag, 원장·검수·운영 기록은 서버에서 20~30건씩 페이지로 조회.

## 공개 주소로 배포할 때

| 환경 변수 | 설명 |
|---|---|
| `ADSFORM_PUBLIC_ORIGIN` | 공개 HTTPS 주소(예: `https://adsform.example`). 설정하면 해당 Host 요청을 받고, 쿠키에 Secure를 붙이며, **테스트 로그인이 기본으로 꺼집니다.** |
| `ADSFORM_HOST` | 서버가 열릴 주소. 기본 `127.0.0.1`. 리버스 프록시가 같은 서버에 있으면 그대로 두면 됩니다. |
| `ADSFORM_TRUST_PROXY` | `1`이면 `X-Forwarded-For`의 첫 주소를 접속 IP로 사용합니다(요청 제한용). |
| `ADSFORM_DEMO` | `1`이면 공개 주소에서도 테스트 로그인을 켭니다. `0`이면 로컬에서도 끕니다. |
| `ADSFORM_ADMIN_PASSWORD` | 테스트 모드가 아닐 때 첫 실행에 한해 `admin` 계정의 비밀번호(12~128자). |
| `ADSFORM_MIN_DWELL` | 미션 최소 체류 시간(초). 지정하면 퀴즈·설문 모두 이 값을 씁니다. |

HTTPS 종료는 Nginx·Caddy 같은 리버스 프록시에서 처리하고, 프록시가 원래 Host 헤더를 그대로 넘기도록 설정해 주세요.

## 운영 범위

충전은 입금 확인 후 수동 승인으로 처리하며 PG 결제는 연결되어 있지 않습니다(PG사 계약 후 연동 필요). 출금은 신청·승인 절차만 있고 실제 송금은 운영자가 직접 처리합니다. 세금계산서 자동 발행, 쿠폰 발급, 외부 오퍼월 API는 연결되어 있지 않습니다. 이용약관·개인정보처리방침은 기본 문안이므로 오픈 전에 사업자 정보와 법률 검토를 반영해 주세요.

테스트 버튼과 예시 계정을 제외한 별도 로컬 데이터베이스가 필요하면 PowerShell에서 `ADSFORM_DEMO`를 `0`으로 설정합니다. 첫 실행에 한해 `ADSFORM_ADMIN_PASSWORD`로 12~128자의 초기 관리자 비밀번호를 지정합니다. 이 모드의 관리자 아이디는 `admin`이며, 저장 파일은 `data/adsform.sqlite`입니다. 데이터 파일과 초기 비밀번호는 Git에 포함하지 않습니다.

`npm test`로 주문·정산·권한·중복 방지, 회원가입·비밀번호·정지, 취소·출금·일괄 검수, 공개 주소 배포 설정을 검증할 수 있습니다.
